Description
This project implements HTML forms with built-in HTML5 validation and Bootstrap 5 styling, themed around a professional VNL 2026 volleyball team tryout portal featuring structural layouts, feedback states, and dynamic submission handling.

---

Tasks Implemented
Task 0: Simple Contact Form using basic HTML tags and labels.
Task 1: HTML5 Validation implementation with required fields, email types, and constraints.
Task 2: Bootstrap Form Styling utilizing grid architecture, form controls, and responsive inputs.
Task 3: Bootstrap Validation Styles incorporating valid and invalid feedback states.
Task 4: Advanced Registration Form containing player names, email, passwords, radio buttons, position checkboxes, and country select elements.
